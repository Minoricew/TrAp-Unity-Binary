## TrAp | Unity-Binary

Vanilla variant Unity binaries for a certain blue box defending game, aka [PvZ Online](https://github.com/pfyy/OpenBachelorS/blob/master/README.md#:~:text=OpenBachelor%20Server.%20For-,PvZ%20Online,-.).

#### How to use

1. Download the repo as zip or use `git clone`
2. `cd $repo_root/bin`
3. `mv UnityPlayer.exe ${the_correct_name}.exe`
4. `mv ./AK_Data/ ./${the_correct_name}_Data/`
5. `mv --force $repo_root/bin/* /path/to/the/game/root/folder/`
6. `start /path/to/the/game/root/folder/${the_correct_name}.exe`

#### What it provides

- No `???-Base??.dll`'s interruptions.
- Do whatever you want to `${the_correct_name}.exe`, such as attaching a debugger to it.
